# Parkinson’s Disease Detection using Machine Learning

This project predicts Parkinson’s Disease using a Support Vector Machine (SVM)
based on selected voice features.

## Features Used
- MDVP:Fo(Hz)
- MDVP:Fhi(Hz)
- MDVP:Flo(Hz)
- HNR
- PPE

## Tech Stack
Python, Pandas, NumPy, Scikit-learn

## How to Run
1. Install requirements
2. Run parkinsons_detection.py
3. Enter sample values to get prediction
